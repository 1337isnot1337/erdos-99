# P99-COMP-001 — Exact triangular-lattice enumeration

**Availability:** open to everyone; no exclusive claim.
**Evidence status:** reproduced finite evidence for the checked program output only.
**Type:** exact finite computation.

## Mathematical question

Let \(u=(1,0)\), \(v=(1/2,\sqrt3/2)\), and \(L=\{au+bv:a,b\in\mathbb Z\}\). For each (n\), determine the minimum diameter among (n)-point subsets of (L) with pairwise distances at least one. Reproduce the supplied exhaustive baseline for (2\le n\le5), then either extend the exact search to (n=6) with a bounded runtime or prove a useful structural reduction for this lattice problem.

## Definitions and hypotheses

Represent a lattice point by its integer coordinate pair ((a,b)). The exact squared distance between ((a,b)) and ((c,d)) is
\[
(a-c)^2+(a-c)(b-d)+(b-d)^2.
\]
Distinct lattice points are at least one unit apart because this expression is a positive integer. Let (L_n) denote the lattice-restricted optimum; it is a separate quantity from the unrestricted planar (D(n)).

## Why it matters

Exact finite models are useful for debugging geometric conjectures and enumeration code. This model is deliberately narrow: a lattice optimum is not a planar optimum, and a lattice pattern does not represent every possible point set.

## Public prerequisites

All definitions and the distance formula are above. The included enumerator uses Python's standard library only. No paper, private code, external package or internet access is needed to reproduce the baseline.

## Starting point

The points ((0,0),(1,0),\ldots,(n-1,0)) have diameter (n-1), so it is enough to search lattice configurations whose diameter is at most (n-1). Translate one point to the origin; every point of a candidate optimum then lies in the finite lattice disk of radius (n-1). The script enumerates every choice of the other (n-1) points in that disk and computes squared diameters using integers. `research/triangular-lattice-baseline.json` is generated by the command below.

## First step

Run the baseline, independently recompute every reported witness's pairwise distances, and verify why the radius bound cannot omit an optimum. For (n=6), first estimate the combination count; seek symmetry reduction or branch-and-bound before launching a long brute-force run.

## Evidence expected

Include the exact enumeration domain, completeness argument, integer-distance implementation, tested runtime, output, and a second check of the reported optimum. If a pruning rule is added, show that it preserves every possible optimum and compare it with the unpruned program on (n\le5).

## Falsification strategy

Try to find a lattice configuration with smaller squared diameter than the reported optimum, a missing lattice point outside the generated coordinate bounds, or a pruning rule that discards a candidate needed for the optimum. An independent enumerator should not import the primary script's candidate list or distance routine.

## Reproduction

From the repository root:

```sh
python3 scripts/triangular_lattice.py --max-n 5
```

The program prints JSON with the exact squared optimum, one witness and the number of anchored subsets examined. The default maximum is five; requesting six may be expensive and should be benchmarked before a longer run.

## Stopping condition

Stop after an independently checked baseline and either an exact (n=6) result with a completeness argument and reported runtime, a proof-level lattice reduction, or a reproducible obstruction to the current search method. A timeout alone is not a mathematical result.

## Scope limit

Every conclusion applies only to the specified triangular lattice and finite values of (n). This task does not establish anything about unrestricted planar minimizers or sufficiently large cardinalities.

## Next questions

Compare the lattice optimum with simple nonlattice configurations, seek an exact formula for (L_n), or use the output as a regression for a separately proved planar method. Do not assume equality (L_n=D(n)).
