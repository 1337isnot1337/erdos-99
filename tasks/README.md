# Research tasks

The task list is intentionally short. Each task is an open, nonexclusive research question with its definitions, evidence boundary and stopping condition in the task file. Search Issues and pull requests for the stable ID before starting; if no overlap exists, anyone may begin without asking permission.

| ID | Question | Type | Starting evidence |
| --- | --- | --- | --- |
| [P99-MATH-001](P99-MATH-001-attainment.md) | Prove attainment of $D(n)$ and audit elementary bounds. | Proof audit | A line configuration gives a finite upper bound; disjoint disks give a coarse lower bound. |
| [P99-COMP-001](P99-COMP-001-triangular-lattice.md) | Reproduce and extend the exact finite search on the triangular lattice. | Exact computation | Standard-library enumerator and exact baseline for $2\le n\le5$. |
| [P99-GEOM-001](P99-GEOM-001-square-benchmark.md) | Give an inspectable proof of the four-point square benchmark $D(4)=\sqrt2$. | Proof audit | The square provides a triangle-free feasible set with diameter $\sqrt2$; cited literature gives the finite-case context. |

Availability in `tasks/index.json` is coordination metadata, not a reservation or a claim about scientific status. A contributor may suggest another self-contained task through an issue.
