# Security policy

This repository contains small research scripts and documentation. Please do not post credentials, private data or a potentially exploitable security issue in a public issue.

Use GitHub's private vulnerability reporting for this repository when available. Otherwise contact the repository maintainers through GitHub and include a concise description, affected path, reproduction steps and impact. Do not include secrets belonging to another person or service.

Security reports are distinct from mathematical counterexamples and research criticism; those are welcome in public Issues or Discussions.
