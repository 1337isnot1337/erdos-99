# Research instructions

For open-ended contributions, start with [autoresearch](autoresearch.md) and its
[standing procedure](docs/research/agent-procedure.md). Check existing handoffs
before drawing a task. Explicit assignments take precedence. Prior-check coverage
is source-bound; unknown coverage does not establish novelty.

Read `docs/STATE.md`, `docs/problem/statement.md`, `docs/research/bottleneck-brief.md`, `docs/research/priority-state.json`, and the chosen route. Then read its full proof prerequisites and `autoresearch.md`. The manifest controls claim lifecycle. A merge, recent date, large section number or certificate pass does not promote a theorem.

Current documentation and tooling are edited normally through Git. Migration
records are historical data; they impose no gate on current changes. No migration
check or migration-ledger refresh is required. Run checks that cover the changed
behavior or scientific claims. An editorial or workflow edit alone does not
require the full theorem-certificate suite or canonical promotion.

Normal setup and checks do not require Linux. Use the platform-neutral
dependency lock and the operating-system commands in `README.md`. Linux and
Bubblewrap are required only by the optional isolated package replay backend.
Report unavailable backend tests as skipped, with their capability reason.

**LEVEL I STATUS: STILL OPEN. C-I CLOSED; C-II OPEN.** A and B remain open. Keep the universal quantifiers over every sufficiently large cardinality and every global minimizer. Keep all source labels, including contact-isolated points. Do not identify a source with a scaffold, smaller optimum, response network or moved endpoint without a theorem.

Work for one bounded 30–60 minute session by default. Fetch current upstream main at each new session; compare priority revision and theorem state with the prior checkpoint. Check open Issues, Discussions and PRs before selecting work and before submitting. Anyone may begin an unclaimed question; claims are advisory. An independent audit may overlap an existing proof effort.

Use `python scripts/find_overlap.py --refresh --json` for body-aware PR/Issue,
Discussion/comment/reply and local-note search with explicit coverage/freshness.
Reuse its cache in the picker with `--coordination-cache PATH`. Keep one current
investigation thread and artifact link. Claims are optional for short sessions;
accepted handoffs and multi-session work benefit from one advisory claim.
No separate session report is required. See `docs/COORDINATION.md`.

Write the exact candidate lemma, hypotheses, implication to a canonical quantity, falsification test and stopping condition before a long search. Use exact arithmetic where an exact certificate exists. Preserve scope and useful regressions. Local optimality, finite rank, one-grain interpolation, infinitesimal feasibility or an abstract swap does not supply a global geometric bridge.

Use an isolated branch/worktree and preserve other work. Submit one inspectable proof, computation, verifier, counterexample, audit or precise handoff. Record source commit, state/priority revision, inputs, commands, arithmetic and limitations. Stop without a PR if no meaningful artifact is ready. Refresh upstream before another session. Do not manufacture PRs or repeat a failed approach without naming the changed hypothesis.

For reusable evidence, the optional `scripts/new_research_package.py` scaffold
provides exact source pins, a deliberately failing checker and Open next questions.
Read `docs/research/research-package-guide.md`; metadata checks execute no commands.

Authorized maintainers start with `python scripts/pr_intake.py plan --refresh`.
Persist exact-head evidence and changed decisions; do not repeat dormant holds or
all-history suites after compaction. Archive publication remains partially reviewed
and never promotes mathematics. Read `docs/research/pr-intake.md` and
`docs/research/research-archive-intake.md`. Scheduling does not authorize a merge.

Contributing agents run `python tools/check_public.py`, checks for their changed behavior, and the verifiers or experiments needed to reproduce their own result. Leave repository-wide theorem-certificate replay to the merging agent, including after rebases; it is not a PR-submission requirement. Record required full replay as **deferred to the merging agent**; `full-verification-required` is a handoff, never a full-verification pass. The merging agent owns required `python tools/run_theorem_certificates.py` replay on the final integration candidate and records its exact commit/tree and result before merging. Workflow-only changes retain their structural-check exemption. See `docs/ci/README.md` for the verification handoff and read it before adding execution infrastructure.

**Permanent agent-only mathematical review policy:** New claims default to unreviewed. Distinguish canonical, audited-working, conditional, exact finite evidence, agent-audited, regression, rejected and superseded claims. Consequential promotion requires **one independent AI-agent audit** of the exact SHA, combining complete proof reconstruction and adversarial bridge/regression checks, plus a same-change update to the manifest, state, route/frontier, dependencies, certificate registrations and generated views. The project owner may operate the reviewer AI session on other agents' work. No second audit or human mathematical review is required. See `docs/REVIEW_POLICY.md`.

For the C-II finite endpoint, a same-cardinality unit-separated strict sub-D
competitor contradicts global minimality. At diameter D the endpoint must remain
triangle-free and strictly improve the lexicographic pair (unit contacts, actual
diameter pairs). Contact loss with a new unit triangle is insufficient; unchanged
contacts with fewer actual diameter pairs is a valid secondary contradiction.
Check all previously inactive upper pairs to exclude replacement diameter pairs.

Preserve mathematical credit and disclose AI assistance. Contribute only material you can license under Apache-2.0; cite external papers rather than copying PDFs or substantial text. Never use an unstated private repository dependency. The published corpus and task prerequisites must stand alone.
