# Hostile audit — additional collapsed common-host obstruction

The result is deliberately narrow.  The interval-Newton script proves the existence
and uniqueness of one closure root in each displayed `ch4`, `ch5`, `ch6`, `ch7`, `ch8`, `ch9`, `ch10`, `ch11`, `ch12`, and `ch13` box, and the
angle script checks only the common-all-outer-host subcase.

The exhaustive step ranges over all 720 cyclic endpoint orders for each box and uses only pairs
of internal trains with disjoint bounded endpoints.  It does not assume that every
pair crosses: it rejects an order because at least one pair that must cross has a
projective gap at most `pi/3`.  The crossing threshold is strict, so the reported
strict margins are sufficient.

No claim is made about multiple hosts, train crossings involving a common bounded
endpoint, arbitrary collapsed roots, nonlinear global integrability, source-point
embedding, diameter bars, or global minimum-diameter optimality.  In particular, the
slow/unfinished full planarization enumeration for `ch4` and `ch5` is not silently
converted into a theorem.

The valid classification is therefore: exact chamber-local common-host exclusion,
proof-only; C-II remains open.
