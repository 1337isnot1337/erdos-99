# Target C: five-no-root k=4 containment closure

Date: 2026-09-20

Status: exact finite closure of the entire five-no-root `k=4,p<=6` rank-density branch. Together with the already committed `k=2`, `k=3`, and `k=5` closures, this proves the factor-three density inequality for every family containing exactly five no-root four-cycles. It does not reduce the 3,874-state generic-H6 endpoint and does not close C-II.

## Statement

Keep the established notation

`delta(A) = r_M(A) - r_Q(A)`.

For five no-root rows in the `k=4` branch, the global coefficient-constraint space `P` has rank one. The dangerous crude regime is `p<=6`.

The verifier proves

> Every five-no-root family in the `k=4,p<=6` branch satisfies `3 delta(A) <= |A|`.

The proof has two parts. First, an exhaustive containment theorem controls every rank-one coefficient line, including lines generated only by singleton local constraints. Second, the resulting uniform inequality leaves only seven `p=6` states, all of which are reranked exactly over `Q` and have defect 11.

## Why the canonical object must be virtual

A previous `p=0` audit considered only rank-one lines generated by empty-block constraints. That is enough for `p=0`, but it is not enough for the whole `p<=6` branch: an actual state can have its rank-one global space generated by a singleton constraint even when no collection of empty constraints generates that line.

For fixed five no-root rows, every actual rank-one `P` must occur as a nonzero local constraint from at least one empty or singleton state. The verifier therefore enumerates every line appearing among local states `0,1,2,4` on every touched block.

For each such line `P`, define a virtual canonical state by

- leaving block `b` empty when its empty-state constraint `E_b` is contained in `P`, and
- completing `b` otherwise.

The virtual canonical state is not required to generate `P` itself. This is deliberate. Of the 177,316 virtual canonical states in the exhaustive scan,

- 111,822 have empty constraints that already generate `P`;
- 65,494 do not.

Those 65,494 cases are exactly the extra coverage needed for singleton-generated rank-one spaces.

`c = |C|`,

and let `H(C)` be the span in the 15-dimensional `T` space of the complete-block relation rows `h_b`, `b in C`.

Write

`d = c - rank_T H(C)`.

## Why containment propagates to every actual state with the same P

Fix `alpha in null(P)`.

If a canonical-empty block is changed to another compatible incomplete state, then `E_b subset P`, so `alpha` annihilates both local quotient coordinates at that block. Its local quotient demand is zero. The corresponding external `T` relation row therefore does not leave `H(C)`.

If a canonical-complete block is changed to a compatible singleton or pair, the canonical complete solution and the incomplete solution cancel the same local quotient demand. Their coefficient vectors differ by an element of the one-dimensional kernel of the three local root-0 rows. That kernel lifts to a scalar multiple of the complete-block relation `h_b`.

Thus every change from the virtual canonical state changes an external relation row only by an element of `H(C)`. The complete-block relation rows still present in the actual state are themselves elements of `H(C)`. Therefore every relation row contributing to `delta(A)` lies in `H(C)`, and

`delta(A) <= rank H(C) = c-d`.

This argument does not require the virtual canonical state itself to generate `P`.

## Uniform defect bound

Let `q` be the number of canonical-complete blocks replaced by incomplete states. Let `p` be the total number of selected root-0 rows in all incomplete blocks.

A canonical-complete block cannot become empty, because its empty-state constraint is not contained in `P`. Hence every replaced canonical-complete block contributes at least one selected row, so

`q <= p`.

The actual row count is

`|A| = 5 + 3(c-q) + p`.

Using `delta(A) <= c-d`,

`|A| - 3 delta(A)`

`>= 5 + 3(c-q) + p - 3(c-d)`

`= 5 + p + 3d - 3q`.

Since `d>=2` and `q<=p`,

`|A|-3 delta(A) >= 11 - 2p`.

Therefore every state with `p<=5` has positive defect. For `p=6`, a negative lower bound is possible only when

`d=2`, `q=6`, and `p=6`.

So the only unresolved form is six singleton replacements of canonical-complete blocks in a `d=2` virtual canonical state.

## Exactness

The orbit and local-constraint construction uses exact integer and rational arithmetic.

Canonical complete-block ranks and containment tests are computed modulo

`P = 2^127 - 1`.

The verifier runs the Lucas-Lehmer primality check. The maximum squared Euclidean norm among all canonical complete and external relation rows is 26, and it checks

`P^2 > 26^15`.

Every relevant determinant has order at most 15. Hadamard's bound therefore makes every modular rank and containment decision equal to the corresponding rational decision; a nonzero rational minor cannot disappear modulo `P`.

The final seven residual states are reranked directly with `Fraction` arithmetic over `Q`. Their maximum squared relation-row norm is 12.

## Consequence for the 44-cycle question

The earlier audits prove the factor-three inequality for every family with at most four no-root four-cycles. The committed five-no-root `k=2`, `k=3`, and `k=5` results, together with this `k=4` closure and the crude exclusion of `k<=1`, now cover every possible five-no-root quotient-kernel regime.

Hence

> every four-cycle family with at most five no-root cycles satisfies `3 delta(A) <= |A|`.

A sufficient 44-cycle family would have `delta(A)=15`, so it would require

`45 = 3*15 <= 44`,

which is impossible.

Therefore

> every hypothetical sufficient 44-cycle family contains at least six no-root four-cycles.

This is a strict improvement over the previous lower bound of five.
