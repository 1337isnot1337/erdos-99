## 1. Positive reciprocal coordinates and $`(2,3)`$-sparsity

Audited source:
\`docs/reports/target_c_positive_reciprocal_internal_train_graph_2026-10-05.md\`.

Use the canonical nonisolated positive-contact core and force-hull augmentation. All added hull sides remain auxiliary zero-force edges. Every bounded augmented face, including every four-sided hull pocket, remains a reciprocal node.

For every oriented physical contact edge $`a\to b`$ with bounded augmented faces $`l,r`$, positive contact equilibrium integrates the bounded-face dual field

```math
q_l-q_r=\alpha_{ab}J(p_b-p_a).
```

The bounded-face dual is connected. Its cycle space has rank $`v-q`$, exactly the number of unloaded core vertices, and is generated by dual facial cycles around those vertices. Positive unloaded equilibrium makes every such dual cycle sum zero, so the reciprocal coordinates $`q_f`$ exist and are unique up to translation.

For an internal stopped train $`\tau=fg`$, if $`w`$ is its terminal unit-edge direction then opposite-side propagation through strict rhombi gives

```math
q_g-q_f=-A_\tau Jw,
\qquad
A_\tau=\sum_{e\in\tau}\alpha_e>0.
```

Hence no internal train is a loop.

Its angular closure column is a positive rescaling of the corresponding bar-rigidity column at the **actual** reciprocal coordinates:
```math
c_\tau
=
\frac1{A_\tau}
\begin{pmatrix}
q_f-q_g\\q_g-q_f
\end{pmatrix}.
```

Canonical \`C-AUGMENTED-TRAIN-RANK\` makes these columns independent. Therefore:

- two distinct trains cannot have the same unordered bounded endpoint pair;
- the internal bounded-endpoint train graph is simple;
- for every bounded node set $`U`$, each nontrivial induced connected component $`U_i`$ satisfies
  ```math
  e(U_i)\le2|U_i|-3;
  
  ```
- equivalently
  ```math
  \boxed{
  e(U)\le
  \sum_{i:\,|U_i|\ge2}(2|U_i|-3),
  }
  
  ```
  and in particular $`e(U)\le2|U|-3`$ for $`|U|\ge2`$.

The third row dependency is the actual reciprocal rotation with face block $`Jq_f`$; it is independent of the two translation dependencies whenever the component contains an edge, because its endpoints have distinct reciprocal coordinates.

## 3. Global exceptional-face return quotas

Audited source:
\`docs/reports/target_c_global_exceptional_face_return_quotas_2026-10-04.md\`.

Let $`\mathcal F`$ be a nonempty selected family of bounded faces of a plane augmentation by auxiliary loaded-to-loaded edges, with degrees $`m_f\ge5`$, and put
```math
Q_{\mathcal F}=\sum_{f\in\mathcal F}(m_f-4).
```

For a minimum endpoint-inclusive physical-contact separator $`S`$ from the selected face boundaries to the actual loaded set, let $`k=|S|`$, let $`U`$ be the selected-side components after deletion, let $`c_U`$ be their number, and let $`K`$ be the retained physical graph plus retained auxiliary loaded-to-loaded edges, with $`c_K`$ components.

The audited theorem is

```math
\boxed{
Q_{\mathcal F}
\le
2k-2c_U-4c_K
\le2k-4.
}
```

The proof has four load-bearing parts, all checked.

### 3.1 Pinned rank plus positive equilibrium

Every selected-side component $`U_j`$ is unloaded. A pinned velocity on $`U_j`$, extended by zero to the rest of the core, would be a mixed flex; canonical mixed rigidity forces it to vanish. Hence the pinned contact matrix has full column rank $`2n_j`$. Positive equilibrium supplies a nonzero left dependence, so
```math
e_j+t_j\ge2n_j+1.
```
Summing gives
```math
e_U+t_U\ge2|U|+c_U.
```

### 3.2 Minimum-separator exposure

Inclusion minimality of a minimum separator makes every $`s\in S`$ exposed on an outer walk of its component in $`K`$. The restoring path from $`s`$ to an actual loaded vertex outside $`K`$ cannot leave a bounded face of $`K`$ without crossing $`K`$. Loaded extremality supplies the same statement when $`s\in B`$.

Every separator vertex is incident with $`K`$. Choosing one outer occurrence of every separator vertex gives
```math
b_K\ge2k-2e_S-a_{\rm out},
```
where physical bridges can contribute two outer occurrences and auxiliary outer occurrences are counted explicitly.

### 3.3 Euler and virtual-triangle cancellation

Exact occurrence counting gives
```math
b_K-F_3(K)+Q^+(K)=4|V(K)|-2e(K)-4c_K.
```

Every bounded triangular face uses an auxiliary edge because the physical contact graph is triangle-free. Charging each triangle to an auxiliary bounded-side occurrence gives
```math
F_3(K)\le2a-a_{\rm out}.
```
Substitution yields the displayed defect/separator theorem.

### 3.4 Endpoint-inclusive Menger and simultaneous quotas

Vertex splitting converts the minimum separator bound into actual physical contact paths, with length-zero starts at loaded boundary vertices handled correctly.

For one degree-$`m`$ face the full-boundary separator therefore has size at least
```math
\left\lceil\frac{m+2}{2}\right\rceil.
```

If $`\ell_f`$ boundary vertices are loaded, define
```math
r_f=
\max\left\{
0,
\left\lfloor\frac{m_f-4}{2}\right\rfloor-\ell_f
\right\}.
```

A grouped integral-flow argument satisfies **all** face demands simultaneously, with globally vertex-disjoint paths from distinct unloaded boundary starts to distinct actual loaded endpoints.

This is independent endpoint/face-label currency. It is not path-length currency and is not second depletion by itself.

The exact verifier passed 153,600 cancellation ledgers, ten separator packets, fourteen simultaneous face-demand packets, and the double-triangle-per-auxiliary-edge regressions.

**Verdict:** canonical-ready.

## 6. Loaded flat pentagons give a second depletion bank

Audited source:
\`docs/reports/target_c_loaded_flat_pentagon_second_depletion_2026-10-05.md\`.

Scope is the canonical full-core Type-II branch with
```math
x_B=b-q=o(D).
```

The exact outer-walk identity then gives $`m_B,u_B=o(D)`$; Type-II disk convergence gives $`q/D\to\pi`$, so the promoted terminal theorem applies.

At all but $`o(D)`$ loaded vertices, both adjacent force-hull sides are actual unit contacts. A regular loaded vertex has contact degree two or three; a degree-three vertex contributes exactly one loaded-to-unloaded contact. Hence the number of regular degree-two loaded vertices is
```math
N_2=q-e_{BI}+o(D).
```

Discarding high-turn vertices costs $`o(D)`$. Such a near-straight inward bounded face cannot be a strict rhombus. Degree-$`\ge6`$ exceptional-face occurrence capacity is at most
```math
6(Q-f).
```

The flat-unit-pentagon compactness lemma was rechecked. A convex unit pentagon with one straight limiting corner is uniquely the triangular trapezoid
```math
(-1,0),(0,0),(1,0),
\left(\frac12,-\frac{\sqrt3}{2}\right),
\left(-\frac12,-\frac{\sqrt3}{2}\right),
```
up to reflection. Its reduced edge phases agree, its interior has no room for an additional unit-separated point, and one pentagon cannot contain two sufficiently near-straight corners.

Therefore there is a marked family of distinct physical pentagons
```math
\boxed{
g_D\ge q-e_{BI}-6(Q-f)-o(D)
}
```
whose incident train family carries $`o(D^2)`$ rhombi.

Each marked pentagon has two actual unit force-hull singleton columns meeting at its selected loaded vertex. They are nonparallel at every finite strictly convex hull vertex, so the selected-face closure rows have exact rank $`2g_D`$.

The deleted family contains all outer-ended trains. By \`C-OUTER-TRAIN-DETERMINATION\` the contact-flex angular map on that family is injective modulo translations. Audit.52 gives $`\sigma_C=0`$. Mantel after deleting the marked-face family, all outer-ended trains, and unused singletons therefore yields
```math
\boxed{
2(f-g_D)\ge2sD+S_U-o(D).
}
```

Combining this with the marked-face lower bound gives the source-level penalty
```math
\boxed{
e_{BI}+6(Q-f)
\ge
sD+2k+\frac{S_U}{2}-o(D).
}
```

Thus a low-outer-walk full-core survivor must pay linearly in actual loaded-to-unloaded attachments or higher-degree exceptional-face defect. This is a genuine second-depletion theorem, but not a contradiction by itself.

The exact verifier passed 80 unit-pentagon pair checks and 23,665 incidence/rank/second-depletion ledgers.

**Verdict:** canonical-ready at the stated $`x_B=o(D)`$ scope.
