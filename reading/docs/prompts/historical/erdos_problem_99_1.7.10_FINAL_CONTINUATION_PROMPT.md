### Section 167 — source-label crossings in the actual response graph

Overlay the noncrossing `X^*->A` source matching with the planar radial response graph.
If a source segment `x-a` properly crosses a response edge `u-y`, then
$$
\boxed{|a-y|<1.}

therefore gives a source conflict with a right vertex on that path.
