## 3. Exact new consequence and why it does not close the problem

Write `f` for the number of bounded nonquadrilateral contact faces and
`Delta=pi/(2sqrt(3))`. Under the stated C dependencies, every hypothetical
lexicographic sequence with `n-v=o(D^2)` must satisfy

```math
\liminf f/D\ge\sqrt\Delta-\pi/4
=0.166914643466509\ldots.
```

The short proof chain is fully accounted for:

```math
T=(b+Q)/2+2f\le h+2f\le q+2f,
\qquad
\liminf(T-q)/D\ge2\sqrt\Delta-\pi/2.
```

The second inequality uses `R/D^2->Delta`, vanishing normalized rhombus excess,
and a round limiting core hull. These follow from `n-v=o(D^2)` and the exact
global density bounds, not from force visibility alone.

Thus sublinear exceptional-face count and subquadratic invisible population
cannot hold together. For any fixed `eta<sqrt(Delta)-pi/4`, a sequence with
`f<=eta D` must instead have `liminf(n-v)/D^2>0`.

Neither remaining branch is excluded. The repository only bounds `f=O(D)`,
which permits the displayed lower bound. A uniform positive Oler excess per
exceptional face is false: DP has excess between zero and `3u`, with `u->0`.
Moreover ordinary facewise Oler cancels all exceptional-face count terms exactly.
A simultaneous shell/source inequality is still missing.

The shortest sufficient scalar endpoint retained by this campaign is

```math
b+\sum_{F\text{ bounded}}(\deg F-4)>2|H|
```

for every sufficiently large hypothetical lexicographic global source. Euler
would then give `e+h<2v-2`, contradicting ZF. Regular shells disprove this
inequality without global optimality. No proof of the full-hypothesis inequality
or formal independence certificate is supplied.
