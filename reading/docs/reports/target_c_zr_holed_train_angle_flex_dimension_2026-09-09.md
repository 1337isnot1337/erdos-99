ZRC extracts one edge-connected strict-rhombic component `Q_*` with `Omega_eta(D^2)` faces, `Omega_eta(D)` trains, and `O(D)` total boundary, but it may have holes. This report gives the exact infinitesimal deformation count that replaces the simply connected train-angle parameterization.

Assign one angular velocity to every train. Opposite sides of every rhombus automatically preserve face closure to first order. The only remaining integrability conditions are vector periods around independent holes: at most two scalar equations per first-homology generator.

If the component has `T` trains and first Betti number `g`, its train-angle infinitesimal flex space has dimension at least

```math
T-2g.
```

Every bounded complementary hole has boundary length at least five, while the total component boundary is `B=2T`. Hence `g<=B/5=2T/5`. Modulo the one global rotation angle, the component therefore has at least

```math
\boxed{T/5-1}
```

non-Euclidean train-angle flex dimensions. For the ZRC component this is `Omega_eta(D)`.

This is the precise neutral space on which the next global locking/Hessian argument must act. It is only an infinitesimal component theorem; external contact attachments and diameter constraints may still kill all of these modes.

## 1. The rhombic component as a train-vector complex

Let `Q` be any finite edge-connected component of strict unit-rhombus faces in the straight-line contact graph.

Write

```math
T=T(Q)
```

for its stopped trains and

```math
B=B(Q)
```

for the number of boundary contact edges, meaning edges incident to exactly one rhombus of `Q`.

ZRC proves the exact train endpoint identity

```math
\boxed{B=2T.}
\tag{ZTF1}
```

Choose for each train `tau` an orientation of its parallel unit contact edges and let

```math
u_\tau\in S^1
```

be the corresponding unit direction.

For every oriented contact edge `e=pq` belonging to train `tau`, there is a sign

```math
\sigma_e\in\{+1,-1\}
```

such that

```math
q-p=\sigma_eu_\tau.
\tag{1.1}
```

---

## 2. One angular velocity per train

Let

```math
t=(t_1,\ldots,t_T)\in\mathbb R^T
```

be train angular velocities. Define an `R^2`-valued antisymmetric 1-cochain on oriented contact edges of `Q` by

```math
\boxed{
\omega_t(e)
:=
\sigma_et_\tau Ju_\tau
\qquad(e\in\tau).
}
\tag{2.1}
```

For a rhombus face, opposite sides belong to the same train with opposite boundary orientations. Their `omega_t` contributions cancel pairwise. Hence

```math
\boxed{
\sum_{e\in\partial F}\omega_t(e)=0
}
\tag{ZTF2}
```

for every rhombus face `F` and every `t`.

Thus `omega_t` is automatically closed on the subspace of cycles generated by face boundaries.

---

## 3. Hole periods are the only remaining integrability constraints

Let

```math
g:=\dim H_1(Q;\mathbb R)
```

be the first Betti number of the rhombic cell complex. Choose cycle representatives

```math
\gamma_1,\ldots,\gamma_g
```

whose homology classes form a basis.

Define the period map

```math
\mathcal P:\mathbb R^T\to(\mathbb R^2)^g
```

by

```math
\mathcal P(t)_j
:=
\sum_{e\in\gamma_j}\omega_t(e).
\tag{3.1}
```

This is a linear map with

```math
\operatorname{rank}\mathcal P\le2g.
\tag{3.2}
```

If

```math
t\in\ker\mathcal P,
```

then `omega_t` has zero period on every graph cycle: face-boundary cycles vanish by ZTF2, and the chosen homology periods vanish by definition. Therefore `omega_t` is exact.

Fix one component vertex `p_0` and set `v_{p_0}=0`. For any other vertex `p`, define

```math
v_p:=\sum_{e\in\pi}\omega_t(e)
\tag{3.3}
```

along any contact-edge path `pi` from `p_0` to `p`. Zero cycle periods make this path-independent.

For every oriented contact edge `e=pq in tau`,

```math
v_q-v_p
=\omega_t(e)
=\sigma_et_\tau Ju_\tau.
\tag{3.4}
```

Since

```math
q-p=\sigma_eu_\tau,
```

we have

```math
(q-p)\cdot(v_q-v_p)=0.
\tag{3.5}
```

Hence every unit contact bar of `Q` is preserved to first order.

Thus:

### Theorem ZTF.1 — holed train-angle flex space

The space of train-angle infinitesimal flexes of `Q`, before adding arbitrary global translations, has dimension at least

```math
\boxed{
\dim\ker\mathcal P\ge T-2g.
}
\tag{ZTF3}
```

## 4. Global rotation is one of the train-angle modes

If

```math
t_\tau=c
```

for every train, then

```math
\omega_t(e)=cJ(q-p).
```

The integrated velocity field is

```math
v_p=cJp+a
```

for a translation vector `a`, i.e. a global infinitesimal Euclidean rotation plus translation.

The constant train-angle vector therefore spans one trivial angular mode inside `ker P`.

Modulo Euclidean motions, ZTF3 gives at least

```math
\boxed{
T-2g-1
}
\tag{ZTF4}
```

nontrivial train-angle flex dimensions whenever the right side is positive.

## 5. Every bounded hole has at least five boundary edges

The rhombic component is a finite planar cell complex. Its first Betti number equals the number of bounded complementary components, counted with the usual planar homology multiplicity; pinched boundary vertices do not create extra first homology without a bounded complementary region.

Boundary edges bordering distinct complementary regions are disjoint as edges. Therefore the sum of the boundary-walk lengths of all bounded holes is at most `B`.

No bounded hole can have boundary length at most three:

- lengths one and two are impossible in a simple straight-line contact graph;
- length three would be a unit contact triangle, forbidden globally.

A bounded hole also cannot have boundary length four. A simple four-cycle of unit contacts is a rhombus. Its two diagonal lengths lie in `(1,sqrt(3))` by the same triangle-free argument used in C42. Split the rhombus along either diagonal. Each triangular half has circumradius

```math
\frac1{2\cos(\theta/2)}<1
```

for the appropriate rhombus angle `theta<2pi/3`. Hence every point of the rhombus lies within distance strictly less than one of a boundary vertex. No additional source point can lie in its interior.

Therefore the four-cycle would bound an actual degree-four contact face. C42 makes that face a strict rhombus, and because it shares boundary edges with `Q`, it would belong to the same edge-connected rhombic component. It cannot be a hole.

Thus every bounded hole has at least five boundary edges.

Consequently

```math
\boxed{
5g\le B.
}
\tag{ZTF5}
```

Using ZTF1,

```math
\boxed{
g\le\frac{2T}{5}.}
\tag{ZTF6}
```

## 6. A universal linear neutral-space fraction

Insert ZTF6 into ZTF3:

```math
\dim\ker\mathcal P
\ge
T-2\left(\frac{2T}{5}\right)
=\frac T5.
```

Therefore:

### Theorem ZTF.2 — one-fifth train neutral space

Every finite edge-connected strict-rhombic component satisfies

```math
\boxed{
\dim\{\text{train-angle infinitesimal flexes}\}
\ge\frac T5.
}
\tag{ZTF7}
```

and modulo Euclidean motions,

```math
\boxed{
\dim\{\text{nontrivial train-angle flexes}\}
\ge\frac T5-1.
}
\tag{ZTF8}
```

No simply connected disk assumption is used.

## 8. Relation to ZRI/ZWT weak trains

ZTF is an unweighted geometric theorem: it does not use the KKT stresses. ZRI/ZWT add the special mechanical information that a linear-by-linear family of train contacts has stress tending to zero while almost all stress lies on a radial path forest.

It is tempting to conclude that a ZTF flex can be chosen only on weak-rich trains. That does **not** follow from the dimension estimate: the `2g` period constraints may couple weak and strong train variables, and the weak-rich train count may be smaller than `2g`.

The correct next problem is weighted:

> Find a nontrivial vector in `ker P` whose train-angle energy under the actual KKT contact stresses is small enough, relative to its boundary/diameter action, to produce a diameter-nonincreasing finite deformation or a forbidden extra near-kernel mode.

This is where the ZRI/ZWT weak-stress information must enter.

## 9. External locking is the surviving obstruction

ZTF concerns the rhombic component with free boundary. In the complete contact framework, boundary vertices also participate in contacts belonging to nonquadrilateral regions or other rhombic components. Those external contact bars can kill component train-angle modes.

The current theorem therefore does **not** contradict mixed universal rigidity. Instead it quantifies exactly what universal rigidity must lock:

```math
\boxed{
\Omega_\eta(D)\text{ intrinsic train-angle modes of one quadratic rhombic sea.}
}
```

All locking information lives on an `O(D)` boundary/attachment system plus the `O(D)` actual diameter constraints.

The next theorem should compare the rank/weight of those locking constraints with the weak-rich train basis and the ZSP/ZHA ordered boundary geometry.
