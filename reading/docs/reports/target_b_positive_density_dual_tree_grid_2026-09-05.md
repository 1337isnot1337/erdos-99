# Erdos Problem #99 - Target B positive-density dual-tree grid extraction

**Date:** 2026-09-05  
**Run type:** exact combinatorial strengthening  
**Target:** Section-50 coherent-component promotion / trimmed-grid interface  
**Depends on:** dual-tree correction DT1-DT2; train tracks cross at most once  
**LEVEL I STATUS:** STILL OPEN

## 1. Purpose

The dual-tree repair proves that an *almost complete* crossing pair of internally noncrossing train families contains an almost-full complete grid. Near-completeness is stronger than is needed for a macroscopic grid.

This report proves a finite positive-density version.

Let

`A={alpha_1,...,alpha_M}`

and

`B={beta_1,...,beta_b}`

be train families in a simply connected train disk. Assume the `B` trains are pairwise noncrossing, and every `alpha` crosses every `beta` at most once. Let

`E=e(A,B)`

be the number of physical `A-B` crossings and write its exact Cartesian density as

`rho=E/(M b)`,

where `0<rho<=1`.

Then there are subfamilies `A' subset A`, `B' subset B` such that every train in `A'` crosses every train in `B'`, with explicit linear lower bounds

`|A'| >= rho^2 M/128`

and

`|B'| >= rho b/4-O(1)`.

If one only knows `E>=rho_0 M b`, the same displayed bounds hold with `rho_0`, because the right sides are monotone in the density.

If `A` is also internally pairwise noncrossing, these subfamilies form a complete positive-density topological grid.

The constants are deliberately conservative. The exponent `rho^2` on the `A` shore is the important improvement over the first draft of this report.

## 2. Dual-tree path representation

Remove the pairwise disjoint proper crosscuts in `B` from the disk. DT1 says that the complement dual `T_B` is a tree with `b` edges, one edge for each `beta in B`.

For each `alpha in A`, DT2 says that its set of crossed `B` trains is exactly the edge set of one simple path `P_alpha` in `T_B`.

Write

`l_alpha=|P_alpha|`.

Then exactly

`sum_(alpha in A) l_alpha = E = rho M b`.                 (2.1)

Thus the geometric crossing problem has become a family of simple paths in a tree with positive average normalized length.

## 3. The long paths carry at least half of the incidence mass

Call `alpha` long if

`l_alpha >= rho b/2`.

The total length of all non-long paths is strictly below

`M rho b/2`.

Since the total path length is `rho M b`, the long paths therefore satisfy

`L_long:=sum_(alpha long) l_alpha >= rho M b/2`.          (3.1)

This weighted statement is stronger for the present purpose than merely lower-bounding the *number* of long paths.

## 4. A long path contains quadratically many far edge pairs

Fix a long path `P` of length `l`. For sufficiently large `b`, hence sufficiently large `l`, put

`q=floor(l/4)`.

Take one edge from the first `q` edges of `P` and one edge from the last `q` edges. There are `q^2` such unordered pairs. Since `q>=l/8` for `l>=8`,

`q^2 >= l^2/64`.                                         (4.1)

Moreover the unique tree subpath joining any such pair contains at least

`l-2q >= l/2-O(1) >= rho b/4-O(1)`

edges.                                                     (4.2)

Call these the **far pairs** generated by `P`.

## 5. Double count far-pair incidences using squared path length

The number of incidences

`(long alpha, far B-edge pair generated by P_alpha)`

is at least

`(1/64) sum_(alpha long) l_alpha^2`.

By Cauchy-Schwarz and the fact that there are at most `M` long paths,

`sum_(alpha long) l_alpha^2`

`>= L_long^2/M`

`>= rho^2 M b^2/4`.                                      (5.1)

Hence the total far-pair incidence count is at least

`rho^2 M b^2/256`.                                       (5.2)

There are fewer than `b^2/2` unordered pairs of `B` edges. Therefore some pair `beta_-,beta_+` is a far pair for at least

`(rho^2 M b^2/256)/(b^2/2)`

`=rho^2 M/128`                                           (5.3)

of the `A` paths.

Let `A'` be the corresponding set of `A` trains.

Let `B'` be the edge set of the unique tree subpath between `beta_-` and `beta_+`, including the endpoint edges. Since this pair was generated as a far pair, (4.2) gives

`|B'| >= rho b/4-O(1)`.                                  (5.4)

A simple path in a tree that contains both endpoint edges `beta_-` and `beta_+` must contain their unique connecting subpath. Hence every `alpha in A'` crosses every `beta in B'`.

This proves the theorem.

### Theorem PDG - positive crossing density forces a complete macroscopic grid

Under the hypotheses above,

`boxed{|A'| >= rho^2 M/128}`,                            (5.5)

`boxed{|B'| >= rho b/4-O(1)}`,                          (5.6)

and

`e(A',B')=|A'||B'|`.

If both original families are internally pairwise noncrossing, `A' union B'` is a complete topological pseudoline grid.

No near-completeness assumption is used.

The product satisfies the additional explicit lower bound

`|A'||B'| >= rho^3 M b/512-O(M)`.                       (5.7)

The `rho^2` shore size is of the natural order for a tree consisting of `Theta(1/rho)` long branches with paths distributed among branch pairs, so a substantially better exponent cannot be expected from density alone without using extra phase/order structure.

## 6. Application to a quadratic coherent phase component

Suppose a Section-50 coherent component has largest class scale `M_0` and total crossing count

`E_H >= kappa M_0^2`

for a fixed `kappa>0`.

There are only three cross-phase pairs, so one pair, say `A-B`, has

`e(A,B) >= kappa M_0^2/3`.

Since `|A|,|B|<=M_0`, its crossing density relative to its own Cartesian capacity satisfies

`rho_AB=e(A,B)/(|A||B|) >= kappa/3`.

Also `|A|,|B|>=kappa M_0/3`, because neither class can support more than `M_0` partners per train.

For sufficiently large `D`, trains in one coherent phase class cannot cross one another: their projective angle difference is `o(1)`, whereas a physical strict unit rhombus in a unit-separated source has acute angle strictly greater than `pi/3` (equality would already create a unit triangle). Thus PDG applies.

Consequently every genuinely quadratic coherent component contains a complete grid with both dimensions `Omega_kappa(M_0)`, without assuming that the component is close to the Theorem-51 cyclic-order bound.

## 7. Interface with penetration-charged cancellation

The companion theorem PC1 removes the old requirement that all trains outside the extracted grid have negligible total displacement. If a complete grid is trimmed to a deep diagonal, every external separator capable of cancelling that diagonal must spend `Omega(grid depth)` physical crossings with the grid. PC1 converts this into

`R >= |A'||B'| + depth*(uncancelled grid diagonal excess)`.

Thus the current bottleneck is quantitative rather than qualitative: determine whether the PDG grid dimensions forced by the retained Section-50 component bounds are already large enough for PC1 to exceed the global rhombus budget `Delta_2 D^2`, or whether several grids must be charged simultaneously. Historical GPS1 material is excluded from this corpus and is not used as an additional premise of PDG.

## 8. Why this does not yet close Target B

For a small fixed crossing density, PDG still permits the extracted grid to be only a small fixed fraction of the full `Theta(D)` train population. PC1 charges arbitrary external cancellation, but the total global rhombus budget is itself `Theta(D^2)` and can still pay that charge for sufficiently small grids.

So the next tasks are:

1. insert the actual Section-50 minimum-degree/component constants into PDG+PC1;
2. strengthen extraction using the extra three-phase cyclic-order structure rather than density alone; or
3. sum penetration charges from several edge-disjoint dense phase grids and control reuse of external crossings.
