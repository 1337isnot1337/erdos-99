# Frozen migration baseline

Exact main commits and trees, complete tracked-file manifests, all open and closed PR records, selected exact PR head OIDs, and hashes for the requested scientific and release documents are recorded in `baseline.json`. Later upstream commits are outside this comparison.

`source-main-snapshot/` contains byte-exact source-main inputs with `.source` filenames where the source content was Markdown. The filename change does not alter bytes; its purpose is to keep historical navigation out of the active repository link graph. These source snapshots are not theorem authority. Destination `docs/state/theorem-state.yaml`, `docs/targets/target-c/CURRENT.md`, and its corrected inverse-phase scope govern current claims.
