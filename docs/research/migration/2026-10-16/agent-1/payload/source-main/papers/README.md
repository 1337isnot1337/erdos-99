# Literature and source files

The paper directories are organized by research role:

- [primary/](primary/) contains the seven supplied papers that form the baseline
  literature used by the canonical theorem state.
- [related/](related/) contains additional papers collected in the [annotated
  literature review](../docs/literature_review.md). Its README.md and SHA256SUMS record
  provenance and checksums.
- [supplementary/](supplementary/) contains additional supplied papers and a thesis
  that support the archive but are not part of the seven-paper baseline.

PDF placement does not promote a paper into the theorem state; use the literature
review and the canonical modules for that distinction.
