## 1. Setup

Consider an eight-no-root state with

`k=4, D=-1, d_root=0, p=3`.

The current k=4 reduction gives a rank-four coefficient space

`P <= Q^8`

with generalized weights at least

`(d1,d2,d3,d4) >= (2,4,5,7)`.

The incomplete-root cost p=3 has only two profiles:

- three singleton blocks; or
- one singleton block plus one pair block.

This note closes the second profile.

## 2. The mixed profile forces d1(P)>=4

Assume the selected incomplete blocks are one singleton plus one pair.

Suppose P contained a nonzero word supported on at most three coordinates. Enlarge its support, if necessary, to a three-coordinate set S. Let q_S be the coefficient-rank loss after deleting S.

The all-depth deletion inequality for an eight-row D=-1 state is

`D(B\\S)=D(B)+2|S|-3q_S >= 0`,

because B\\S has five no-root rows. At |S|=3 this gives q_S<=1. Since the chosen nonzero word is supported in S, q_S>=1. Hence q_S=1.

The five-row shadow therefore has coefficient rank three, hence k=2, and

`D_5 = -1 + 6 - 3 = 2`.

Its unstripped incomplete-root cost remains p=3. The committed sharp five-row theorem for

`D=2, k=2, p=3`

proves that all three units of incomplete-root cost must be three distinct singleton blocks; no pair state is allowed, even if an incomplete block becomes untouched in the shadow.

But deleting external rows does not change the selected root-row profile: our shadow still has one singleton plus one pair. Contradiction.

Therefore the mixed profile has

`d1(P)>=4`.

Generalized Hamming weights are strictly increasing, so together with the current bounds,

`(d1,d2,d3,d4)(P) >= (4,5,6,7)`.

This sharpening is specific to the mixed profile. It is not claimed for the surviving three-singleton profile.

## 3. Support-level consequences

For a touched root block b, let I_b be the set of external-cycle occurrences touching b.

For an actual-empty block, the committed local-block rule gives dim(E_b)=1 or 2. Since E_b<=P,

- dim(E_b)=1 requires |I_b|>=4;
- dim(E_b)=2 requires |I_b|>=5.

A nonzero singleton coefficient line also requires at least four incident external coordinates.

For two nonzero local spaces supported inside occurrence sets I,J, the generalized weights give these necessary conditions:

- line-line: |I intersect J|>=4 or |I union J|>=5;
- plane-line: |I intersect J|>=4 or |I union J|>=6;
- plane-plane: |I intersect J|>=5, or both |I intersect J|>=4 and |I union J|>=6, or |I union J|>=7.

The rank-four global space must be generated by actual-empty local spaces together with the singleton line; the selected pair contributes no coefficient constraint. Thus the sum of nominal local dimensions must be at least four, and the union of their occurrence sets must contain at least seven external coordinates because d4(P)>=7.

## 4. Touched-block bound

Let h be the number of touched root blocks and e the number of touched actual-empty blocks.

At most two selected incomplete blocks are touched in the mixed profile. Since d_root=0, the touched complete-root rows are independent, so there are at most 15 touched complete blocks. Hence

`e >= h-17`.

Every empty block has at least four external incidences, while every other touched block has at least one. The eight no-root cycles contribute exactly 32 cycle-block incidences. Therefore

`32 >= 4e + (h-e) = h+3e >= 4h-51`,

so

`h<=20`.

## 5. Complete-row independence and face-local capacity

For a candidate root-state assignment inside a fixed touched set T, let I be the touched incomplete blocks and C=T\\I the touched complete blocks.

Because d_root=0, C must be independent in the triangle-row space H. Also k=4 gives four independent external relation directions. The committed face-local containment theorem places every external relation lift in H(T). Passing from the full complete-root span to the smaller touched-complete span cannot reduce the available quotient dimension, so a necessary condition is

`rank H(T) - rank H(C) >= 4`.

The certificate checks both this condition and independence of C exactly.

## 6. Exact support certificate

Ignore cycle phases and retain only the multiset of the eight tetrahedral four-supports on seven labels. A support occurs at most three times because it has only three no-root four-cycle orientations.

The verifier independently regenerates all S7-orbits of such multisets by canonical augmentation and asserts the already certified orbit counts

`1,1,4,14,61,268,1283,6032,27763`

for sizes zero through eight.

Among the 27,763 size-eight orbits, exactly 13,574 have h<=20.

For each of those 13,574 orbits the verifier exhaustively enumerates every pairwise-compatible set of individually eligible actual-empty blocks. It then enumerates every mixed singleton-plus-pair placement, including all four touch patterns:

- both selected blocks untouched;
- singleton touched and pair untouched;
- singleton untouched and pair touched;
- both touched on distinct blocks.

A touched singleton is allowed either to contribute zero constraint or, whenever its incidence set is large enough, an arbitrary line supported inside that incidence set. This deliberately enlarges the search. The verifier requires only the necessary generator, generalized-weight, complete-row independence, and face-local capacity conditions above. It does not require phases or actual gluing of the nominal local spaces to one common P.

The executed result is

`support_multiset_orbits_size_8 = 27763`

`touch_at_most_20 = 13574`

`mixed_profile_survivors = 0`.

Therefore no mixed singleton-plus-pair state exists.

## 7. Exactness of rank decisions

Support canonicalization and incidence tests use exact integer/set arithmetic.

Triangle-row ranks are computed modulo 2^31-1. The verifier checks this Mersenne prime with Lucas-Lehmer. Triangle rows have squared Euclidean norm three and rank at most 15. It checks

`(2^31-1)^2 > 3^15`.

Hadamard's inequality then puts every relevant nonzero integer minor strictly below the modulus in absolute value, so modular rank equals rational rank.

## 8. Consequence

The branch

`k=4, D=-1, d_root=0, p=3`

For that remaining profile the generic current bound still starts at
