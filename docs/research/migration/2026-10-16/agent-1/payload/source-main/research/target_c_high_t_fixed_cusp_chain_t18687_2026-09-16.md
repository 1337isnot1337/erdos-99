## 2. A sliding-window budget lemma

Fix an integer `r>=1`. Consider every length-`r` interval window of consecutive internal rectangle interfaces which avoids the unique hub interface and the fixed `O(1)` end indices excluded by the strip setup. For fixed `r`, all but `O(r)` of the possible windows are admissible, so their number is

\[
W_r=m-O(r)=0.0000226D-o(D).
\tag{FC.17}
\]

For an admissible window `W`, put

\[
J(W):=\sum_{i\in W}J_i.
\tag{FC.18}
\]

Every interface belongs to at most `r` length-`r` windows. Since all `J_i` are nonnegative,

\[
\sum_{W}J(W)
\le r\sum_iJ_i
<rKD+o(D).
\tag{FC.19}
\]

Therefore some admissible window satisfies

\[
J(W)
<{rKD+o(D)\over0.0000226D-o(D)}

\tag{FC.20}
\]

The exact margin (FC.16) gives, for sufficiently large `D`,

\[
\boxed{J(W)<1{,}109{,}000r.}
\tag{FC.21}
\]

Take the `r+1` rows bounding this window. This proves (FC.1)--(FC.2) directly.

The sliding-window estimate is strictly stronger than merely finding `r` individually good interfaces: it controls the **sum of all finite-defect, switching-mass, and angular-defect budgets across the entire chain linearly in `r`**.

This argument is stated for each fixed `r`; a separate diagonal theorem handles growing `r` without assuming uniformity of the original asymptotic errors.

### 6.1 Reaction supports on different strips are disjoint

The one-sided hub theorem gives more than a common orientation. Suppose the selected chain lies on the `i<k` side of the hub. Then every switch is a **start** of the interval

\[
I_h=\{a_h+1,\ldots,b_h\},
\]

so an actual diameter row can switch at only one interface in the chain, namely its unique left endpoint. On the `i>k` side every switch is instead the unique right endpoint, and the same conclusion holds. Therefore

\[
\boxed{
H_{sw,i}\cap H_{sw,j}=\varnothing
\qquad(i\ne j).
}
\tag{FC.41}
\]

In particular the union bound (FC.24) is an exact disjoint-union count, and reaction nondegeneracy gives the additional lower bound

\[
\boxed{
r\le\left|\bigcup_{i=0}^{r-1}H_{sw,i}\right|
<1{,}109{,}000r.
}
\tag{FC.42}
\]

For each interface choose a minimal reaction-generating Caratheodory set

\[
J_i\subseteq H_{sw,i},
\qquad 1\le|J_i|\le2.

Equation (FC.41) makes these sets pairwise disjoint, so

\[
\boxed{
r\le\left|\bigcup_{i=0}^{r-1}J_i\right|\le2r.
}
\tag{FC.43}
\]

Thus **no single diameter bar can brace two different strips of the extracted chain**. The remaining multi-strip regression must use a fresh one- or two-bar reaction support at every successive interface. The bars may still meet at common hub-side source vertices or cross as a thrackle; that geometry remains open.
