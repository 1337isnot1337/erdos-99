## A consequential proof correction

The corpus already contained the Audit.236 repair from unmerged source PR #947,
but its manifest still declared the old Audit.202 proof and stronger intermediate
conclusions canonical. The actual-contact route estimate is

`d_G(p,q) <= C_M (|p-q|+1) + 2T_M(D)`.

Consequently integrating `K/D` edge errors leaves the additive term
`2K*T_M(D)/D`. The double-limit tail assumption can make that error small;
it does not bound it by `K'|p-q|/D` for nearby endpoints. The global Lipschitz
chart and `q=O(D^(4/5))` inference in Audit.202 were unsupported.

Publication state `2026-10-15.publication.1` explicitly withdraws those two
assertions. The full original proof is retained with a prominent correction.
The claim ID `C-GLOBAL-INVERSE-PHASE-FACE-TAIL-EXCLUSION` moves to
**audited-working** with the supplied [Audit.236 sequence proof](../audits/target_c_global_inverse_phase_face_tail_second_referee_2026-10-10.md).
Its common-frame and face-tail hypotheses, actual global source, lexicographic
minimality and all contact isolates are unchanged. No other source-PR promotion
is adopted. No declared theorem depended on this ID at the reviewed base.

The corrected argument chooses a diagonal cutoff with
`C_M D^(-1/4) -> 0` and `T_M(D)/D -> 0`. At radius `r=D^(3/4)` each boundary
patch is within `epsilon_D -> 0` of one translated lattice. The canonical
local curved-boundary capacity theorem sums over `O(D/r)` patches to give
`q=O(D*epsilon_D + D^(5/6) + D^(1/4))=o(D)`, contradicting
`q>=h>=ceil(D)`. This was independently reconstructed by publication agents.
The current review policy requires one independent AI-agent mathematical audit before canonical reuse; no canonical promotion is made here.
A second source PR #947 clarification repairs an overstatement in the nested-hexagon
report: the checker tests 225 chosen polynomial fields over `M=3,...,12`, rather
than every arbitrary field. Its historical JSON key is explicitly identified as
overstating those samples. The all-field/every-`M` result remains an analytic
ring/radial theorem; neither its lifecycle nor exact verifier bytes change.

The dependency now names that local-capacity theorem, rather than a theorem
requiring the unsupported global Lipschitz chart. Claim count remains 451 and
declared edge count 845; canonical count is 371 and audited-working count 4.
Level I, A, B and C-II remain open; C-I remains closed in its existing scope.

```sh
python tools/verify_publication_sources.py
```

```sh
python tools/verify_publication_sources.py --source-repo /path/to/private-source --output /tmp/source-byte-audit.json
```
