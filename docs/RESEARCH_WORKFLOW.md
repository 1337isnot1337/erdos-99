# Scientific workflow

Read [autoresearch](../autoresearch.md), [coordination](COORDINATION.md), and [review policy](REVIEW_POLICY.md). Work from the exact state and priority revisions. Complete statements, dependencies, proofs, regressions, arithmetic, source inputs and limitations accompany every substantive result.

Contributing agents reproduce their own evidence and run focused checks and corpus integrity. Required repository-wide certificate replay is **deferred to the merging agent**, with the planner's classification and unchecked scope stated in the PR. This handoff permits submission and does not assert full verification. The merging agent performs required full replay on the final integration candidate and records its exact commit/tree, PR head, base, environment, commands and results before merging. Workflow-only changes retain their structural-check exemption; declared mathematical inputs do not. See [verification ownership](ci/README.md#verification-ownership).

Canonical promotion is a single reviewed transaction: update state_version, docs/STATE.md, the affected route/current frontier, active prompt when changed, claim dependencies and certificates, then regenerate theorem views and artifact metadata. The merging agent runs full verification for canonical/shared-foundation impact. Exactly one independent AI-agent mathematical audit is required for consequential promotion. The project owner may operate the reviewing agent for other agents' work; the audit must independently reconstruct the complete proof, test the decisive bridge and regressions, and record the exact SHA, reviewer/model, evidence, verdict and limitations. No second or human mathematical review is required. A report merge alone does not promote it.

Use unreviewed, audited-working, conditional, regression, rejected and superseded statuses honestly. Preserve correct subclaims and predecessor attribution when narrowing an overstrong result. Do not substitute a finite calculation for an unencoded global realization implication. Reviewed findings feed the priority log and task catalogue; record a scientific reason for changing attention weights or retiring a scoped family.
