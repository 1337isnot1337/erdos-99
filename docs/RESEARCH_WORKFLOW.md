# Scientific workflow

Read [autoresearch](../autoresearch.md), [coordination](COORDINATION.md), and [review policy](REVIEW_POLICY.md). Work from the exact state and priority revisions. Complete statements, dependencies, proofs, regressions, arithmetic, source inputs and limitations accompany every substantive result.

Canonical promotion is a single reviewed transaction: update state_version, docs/STATE.md, the affected route/current frontier, active prompt when changed, claim dependencies and certificates, then regenerate theorem views and artifact metadata. Run full verification for canonical/shared-foundation impact. Independent human review is required for consequential promotion. A report merge alone does not promote it.

Use unreviewed, audited-working, conditional, regression, rejected and superseded statuses honestly. Preserve correct subclaims and predecessor attribution when narrowing an overstrong result. Do not substitute a finite calculation for an unencoded global realization implication. Reviewed findings feed the priority log and task catalogue; record a scientific reason for changing attention weights or retiring a scoped family.
