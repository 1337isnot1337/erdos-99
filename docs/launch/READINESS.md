# Publication readiness

The repository is an evolving research project. Level I remains open; the
[current theorem state](../STATE.md) records the accepted claims and their scope.

## Current checks

Current code checks theorem metadata, proof and certificate dependencies,
task navigation, generated mathematical views, and local links. Release tooling
also scans current files and reachable Git history for credentials and checks
the workflow configuration.

Migration checks have been deleted. Historical import inventories, source pins,
rights ledgers and transformation records do not gate current edits or releases.
Ordinary documentation edits use structural checks; mathematical or executable
changes use the relevant tests and certificates.

## Evidence

See [release verification](GATE_2_VERIFICATION.md) for the full local command and
[publication status](RELEASE_CANDIDATE.md) for its interpretation. Each test or
release report should state what ran and on which revision. Earlier results
remain evidence for their own tested scope. This page does not claim a new full
certificate replay.

Hosted jobs have not supplied successful execution evidence. Skipped jobs and
startup failures do not count as verification. Local verification is supported.

The owner has authorized the first-party project material and ordinary Git
attribution. No migration-era manifest reattestation is required. Keep the
project license, contributor credit and applicable third-party notices.
Changing repository visibility remains a separate owner action.
