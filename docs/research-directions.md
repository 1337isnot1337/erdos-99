# Initial research directions

The first beta deliberately uses questions that can be understood from the public problem statement and elementary Euclidean geometry. Each task is self-contained; none depends on private route maps, certificates or reports.

1. **Attainment:** make the compactness argument for (D(n)) precise for every integer (n\ge2). This checks that the word “minimum” in the problem is justified.
2. **Exact finite model:** reproduce and extend an exhaustive search on a triangular lattice using integer arithmetic. This is useful as a finite regression and as a test of exact enumeration methods, with an explicit warning that the lattice is a restricted model.
3. **Small benchmark audit:** supply an accessible proof that the unit square is a global minimum-diameter arrangement for four points, or identify a flaw in that benchmark. The square itself is triangle-free; this illustrates why the theorem is eventual rather than a statement for every (n).

Later tasks may be added when their complete definitions, dependencies and falsification tests fit in the public repository. A maintainer may update this page and `tasks/index.json` as priorities change. There is no automated research director in Phase 1.
