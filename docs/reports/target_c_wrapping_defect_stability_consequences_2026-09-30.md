# Wrapping-root defect stability: consequences

Set a=pi D-P and b=P-q. Inequality (1) gives

a/2+b+k <= Delta(lambda)D+o(D).

Thus a+b+k <= 2Delta(lambda)D+o(D), and

q-k = pi D-(a+b+k) >= (pi-2Delta(lambda))D-o(D).        (4)

Since k=d_H+s_Z and h=q-d_H, h>=q-k. In the Woodall forest branch
c_H=d_H<=k, so c_H/D<=Delta(lambda)+o(1).

At lambda=lambda_1, Delta=0. Therefore

pi D-P=o(D), P-q=o(D), k=o(D), Qloc=o(D),
Y=o(D), Z=o(D), M=o(D).

Hence

S=(lambda_1+pi/2)D+o(D),
q-k=pi D+o(D),
q-k-S=(pi/2-lambda_1)D+o(D).

This is proof-only; no computation is load-bearing.
