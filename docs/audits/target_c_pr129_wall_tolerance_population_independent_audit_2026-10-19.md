## All-`m` source inequalities and slack

For integer `m>=7`, let

```text
d = m^2 - 6m - 3,
u = (1,0),
v = (sqrt(d)/(2m), sqrt(3)(m+1)/(2m)),
A_m = { i*u + j*v : 0<=i,j<=m }.
```

The identity `d+3(m+1)^2=4m^2` gives `|u|=|v|=1`. Also `d_7=4`,
`d_(m+1)-d_m=2m-5>0`, and `d<m^2`, so `0<cos(phi)=sqrt(d)/(2m)<1/2`.
Thus the angle is strictly between 60 and 90 degrees and tends to 60 degrees.

For an integer difference `(a,b)`,

```text
|a*u+b*v|^2 = a^2+b^2+2ab*cos(phi).
```

If one coordinate is zero, every nonzero difference has squared length at
least one, with equality only for an axis unit step. If `ab>0`, the squared
length is greater than `a^2+b^2>=2`. If `ab<0`, put `r=|a|`, `s=|b|`.
Then

```text
|a*u+b*v|^2 = (r-s)^2 + 2rs(1-cos(phi)) > (r-s)^2+rs >= 1,
```

because `cos(phi)<1/2` and `r,s>=1`. The only unit contacts are therefore
horizontal and vertical neighboring labels. The contact graph is exactly the
rectangular grid, has `2m(m+1)` edges, is bipartite, and has no isolated
labels.

For every source pair, its index difference lies in `[-m,m]^2`. The squared
norm is a convex quadratic on this square, so its maximum is attained at a
corner. The same-sign corners are largest, giving

```text
D_m^2 = m^2(2+2*cos(phi)) = 2m^2 + m*sqrt(d).
```

This proves every upper pair bound against `D_m`; the opposite-sign corners
are smaller. Since `0<cos(phi)<1/2`, `sqrt(2)m < D_m < sqrt(3)m`.

The hull is the parallelogram generated by `mu` and `mv`. Its area is
`sqrt(3)m(m+1)/2`, its perimeter is `4m`, and its population is
`(m+1)^2`. Substitution in the all-label Oler expression gives

```text
2*area/sqrt(3) + perimeter/2 + 1 - |A_m|
= m(m+1) + 2m + 1 - (m+1)^2
= m.
```

The slack identity is exact for every `m>=7`, not a fit to the verifier's
four sample sizes.

## Fixed-wall capacity and wall tolerance

Each unit rhombus of the parallelogram can be split along its shorter
diagonal `u-v`. Either triangle has circumradius squared

```text
R^2 = |u-v|^2 / (4*sin(phi)^2) = 1/(2(1+cos(phi))) < 1/2.
```

For a point `x` in such a triangle, write its barycentric coordinates as
`x=sum(lambda_i*w_i)`, with nonnegative `lambda_i` summing to one. If `o` is
the circumcenter, expanding squares gives

```text
sum(lambda_i*|x-w_i|^2) = R^2 - |x-o|^2 <= R^2 < 1.
```

At least one existing vertex is therefore strictly within unit distance of
`x`. The triangles cover the closed parallelogram, so its fixed-wall
insertion capacity is zero, including on cell boundaries.

The two-side refill report gives squared motion gap
`g_L=3/(250000*L^14)` and tolerance
`eta_L=g_L/(4*(L+1))=3/(1000000*L^14*(L+1))`. The conversion is exact. In
this family `L=2m` and the outer wall equals the reference grid wall, so its
ordered wall error is exactly zero and hence is strictly below every positive
`eta_(2m)`. The scale also matches the stated perturbation margin: if a
reference target-to-wall distance is at most `L+1` and a wall vertex moves by
at most `eta_L`, expansion of the square gives

```text
|x-(w+delta)|^2 >= |x-w|^2 - 2(L+1)*eta_L
                 = |x-w|^2 - g_L/2.
```

The dropped `|delta|^2` term is nonnegative, so a reference squared gap
`g_L` retains at least `g_L/2`. This verifies the tolerance scale and the
zero-error instance needed here. It
does not re-prove the separate general perturbation and exterior-shielding
argument for arbitrary nearly matching simple cycles in the predecessor
two-side theorem.

## Population payment

The full source has `(m+1)^2` labels. Its outer cycle has `4m` labels and its
strict interior has

```text
K = z = (m-1)^2.
```

For the square frame the two-side construction removes `J=2m-1` distinct
wall labels and supplies only `K` strict target positions. Its funding
condition is `K-z>=J`; here `K-z=0`, so the condition fails by exactly
`J=2m-1`. Restoring all removed source labels requires `z+J=K+J` targets;
the construction is short by `J`. The local wall residual expression in the
source is also exactly `m`, but it does not change this population arithmetic.

grid has diameter `sqrt(2)m < D_m`, so `A_m` is nonglobal.
